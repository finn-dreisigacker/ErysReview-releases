# ErysReview – Releases

ErysReview ist eine Desktop-App (macOS, Windows) zur Auswertung Cellpose-segmentierter Erythrozyten-Aufnahmen.

Dieses Repository enthält **nur die Release-Pakete** (kompilierte App) für den eingebauten Updater, keinen Quellcode.

- Die Nutzung erfordert eine gültige Lizenz.
- Neue Versionen erscheinen unter [Releases](../../releases) und werden in der App über *Hilfe › Nach Updates suchen* angeboten.
